# 徒手拆机甲 · 林间小院

一个带开始菜单、四张可探索地图的明亮 2D 个人博客。文章放在书屋，公开项目放在工作室，教育、经历与荣誉合并在住处档案，花园留给小游戏。React / TypeScript 管理阅读与目录，Phaser 4.2.1 管理角色、地图和环境反馈，Tiled JSON 管理空间物件。

## 本地预览与检查

```sh
npm ci
npm run dev
```

默认本地预览包含 4 篇带明确标识的待核对草稿。首页支持 WASD / 方向键移动、E 互动、F 踢球、M 小院地图，点击地面也可以行走；手机提供方向按钮。正文打开时移动暂停，关闭后留在原处。独立 `/archive`、`/projects`、`/about` 和 `/posts/:slug` 不依赖地图启动。

```sh
npm run check       # 类型、可达性、内容引用、草稿隔离、自动收录
npm run build       # 仅正式文章，自动重新生成内容，默认不带草稿
npm run build:preview # 私有预览，包括待核对草稿
```

公开发布只能使用 `npm run build`，且应确认托管受众。当前站点设置为仅所有者访问，并设置 noindex；noindex 不是访问控制。后续公开上线再调整站点访问权限和索引元数据。

## 场景与交互

- 所有地图覆盖视口，窄屏和超宽屏跟随角色，保留完整的可走区域。
- 主院采用独立房屋、门、树、灌木和长椅；室内采用清空家具的底图、独立家具纹理与前景门柱。图层按脚点排序，遮挡与地面碰撞分别配置。
- 点击物件自动沿小路前往；手动移动有四朝向、八帧步态和加减速。交互仅靠近时显示。
- 开门与进入房间有衔接动画；菜单、地图和阅读暂停整个场景，包括转场计时器。减少动态效果设置会跳过过渡。
- 广场踢球有碰撞和进球反馈；室内有电路、记忆配对及两处小彩蛋，成绩存在本机，不限制文章访问。
- 氛围音乐为 Kevin MacLeod 的 Morning（CC BY 4.0），手动开启，可调音量；阅读时自动降低音量。
