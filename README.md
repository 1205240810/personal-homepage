# 徒手拆机甲 · 河谷漫游

一个可滚动探索的明亮 2D 个人博客：河湾书屋与水车坡地由浮桥相连，两处室内承接文章和项目。调节两只水阀、接通工坊回路，开启返回河湾的索道。教育、经历与荣誉合并在门边档案中。React / TypeScript 管理阅读与目录，Phaser 4.2.1 管理角色、地图和环境反馈，Tiled JSON 管理空间物件。

## 本地预览与检查

```sh
npm ci
npm run dev
```

默认本地预览包含 4 篇带明确标识的待核对草稿。首页支持 WASD / 方向键移动、E 互动、Shift 快走、M 河谷地图，点击地面也可以行走；手机提供方向按钮。正文打开时移动暂停，关闭后留在原处。独立 `/archive`、`/projects`、`/about` 和 `/posts/:slug` 不依赖地图启动。

```sh
npm run check       # 类型、可达性、内容引用、草稿隔离、自动收录
npm run build       # 仅正式文章，自动重新生成内容，默认不带草稿
npm run build:preview # 私有预览，包括待核对草稿
```

公开发布只能使用 `npm run build`，且应确认托管受众。当前站点设置为仅所有者访问，并设置 noindex；noindex 不是访问控制。后续公开上线再调整站点访问权限和索引元数据。

## 场景与交互

- 两张 2400×1440 的室外地图在所有屏幕上跟随人物滚动；相机始终覆盖视口。书屋和工坊按同一人物尺度缩放室内结构及家具。
- 水岸由与碰撞相同的多边形绘制，草地均可行走，树干、建筑和家具单独阻挡。石路负责引导，不构成草地空气墙。
- 浮桥初始低于岸线；两只水阀都参与调水，达到金线后桥面升起、实际通路开启。工坊的电路完成后，水车运转，索道可往返起点。
- 角色使用原创四方向、每方向八帧图集，按行走距离播放并统一脚底锚点。树冠、桥绳、室内家具与门柱使用独立前景层。
- 菜单、地图、阅读暂停整个场景；关闭后保持原位置。减少动态效果设置跳过镜头、机关和门的过渡。
- 旅行卡片和两处小秘密是可选探索；阅读、项目与档案始终可直接访问。探索进度保存在本机。
- 氛围音乐为 Kevin MacLeod 的 Morning（CC BY 4.0），手动开启，可调音量；阅读时自动降低音量。

关卡与扩建约定见 [河谷动线](docs/LEVEL_DESIGN.md)。
