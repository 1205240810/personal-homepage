# 徒手拆机甲 · 工作台与机甲档案馆

同一份内容，两种进入方式。`/` 是机甲引导页；`/workbench` 保留 B 精密工作台，直接阅读文章、访问个人档案，并在同一台小电脑里试用 OSPF 地址规划和相册规则筛选。`/explore` 是可选的 2.5D 机甲世界：沿环形维修栈道进入驾驶舱、胸腔档案库和检修工坊。

## 本地预览与检查

```sh
npm ci
npm run dev
npm run check
npm run build          # 仅正式文章
npm run build:preview  # 包含明确标注的私有草稿
```

默认本地预览包含四篇待核对草稿，B 首页精选只展示正式文章。公开发布使用 `npm run build` 并核对托管受众。当前仅所有者访问，noindex 不是访问控制。

## 两种访问方式

- 工作台：作品、文章、关于均有独立地址；引导页和工作台不加载 Phaser。网络示例本地计算地址，应用、下发与 Ping 明确为模拟回执；相册示例使用六张公开照片与原项目规则标签。
- 机甲：WASD 或方向键移动，E 互动，M 拆解图，Shift 快走；点击栈道或门也可以前往。手机提供四方向和互动按钮。
- 驾驶舱合并简介、教育、经历与荣誉；胸腔档案库自动收录所有栏目；检修工坊提供 GitHub 项目和可选电路互动。全部舱门和内容从一开始开放。
- 阅读与拆解图暂停移动。关掉阅读保持位置，出舱返回各自门前。探索位置与发现仅保存在本机。
- 双轴镜头覆盖视口；外景地面与可见栈道对齐，室内地面和家具分离，角色可绕桌行走并按脚底深度遮挡。按系统减少动态效果设置跳过过渡与镜头缓动。
- 氛围音乐保留 Kevin MacLeod 的 Morning（CC BY 4.0），手动播放，可调音量，阅读时降低音量。
