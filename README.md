# 徒手拆机甲 · 工作台与机甲档案馆

同一份内容，两种进入方式。默认 `/` 是「精密工作台」：直接阅读文章、访问项目、查看个人档案，并能试用一小段 OSPF 路径切换演示。`/explore` 是可选的完整侧视机甲：沿维修通道进入驾驶舱、胸腔档案库和检修工坊，随时返回工作台。

## 本地预览与检查

```sh
npm ci
npm run dev
npm run check
npm run build          # 仅正式文章
npm run build:preview  # 包含明确标注的私有草稿
```

默认本地预览包含四篇待核对草稿，B 首页精选只展示正式文章。公开发布使用 `npm run build` 并核对托管受众。当前仅所有者访问，noindex 不是访问控制。

## 两种访问方式

- 工作台：作品、文章、关于均有独立地址；默认首页不加载 Phaser。拓扑图是浏览器本地简化演示，完整项目通过外链访问。
- 机甲：A / D 或左右方向键移动，E 互动，M 拆解图，Shift 快走；点击通道或门也可以前往。手机提供左右方向和互动按钮。
- 驾驶舱合并简介、教育、经历与荣誉；胸腔档案库自动收录所有栏目；检修工坊提供 GitHub 项目和可选电路互动。全部舱门和内容从一开始开放。
- 阅读与拆解图暂停移动。关掉阅读保持位置，出舱返回各自门前。探索位置与发现仅保存在本机。
- 横向镜头覆盖视口；人物在前景维修道上移动，背景机体和家具不作为可行走区域。按系统减少动态效果设置跳过过渡与镜头缓动。
- 氛围音乐保留 Kevin MacLeod 的 Morning（CC BY 4.0），手动播放，可调音量，阅读时降低音量。
