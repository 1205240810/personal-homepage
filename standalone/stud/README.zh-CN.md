# 绯夜 · 五张梭哈

独立、可离线运行的中文双人五张梭哈。酒红绒面牌桌、黄铜色筹码、四轮明牌进程、逐步全下发牌、赛后行动复盘与原创合成背景音乐。仅使用不可购买、不可兑现的虚拟筹码；没有账户、支付、广告、遥测或外部音频依赖。

## 运行与交付

- 直接双击 `绯夜五张梭哈.html`：单文件便携版，内联 JS/CSS/音频程序，不依赖 CDN。
- 源码：React 19.2.6、TypeScript、Vite。
- 安装：`npm ci`；开发：`npm run dev`。
- 验证：`npm run typecheck`、`npm test`；构建：`npm run build`。
- 重建便携版：`npm run build:portable`。
- `dist/` 是普通静态站点构建；托管任意子目录时建议使用便携 HTML，或在构建中设置 Vite 的 base。

## 本作的确切规则

规则参考：[Pagat – Five Card Stud](https://www.pagat.com/poker/variants/5stud.html)，核对日期 2026-10-08。以下是明确的双人家庭简化变体，不声称完全遵循赌场限注版本。

1. 52 张标准牌，无大小王。每场双方各 500 筹码；最多十手，任一方归零提前结束。场末比较筹码；胜负不会改变下场固定初始配置。
2. 每手双方底注 5；若较短筹码不足 5，双方底注均为较短筹码，随后直接跑完牌面。上一手剩余筹码延续。
3. 先发每人一张暗牌、一张明牌，第一轮下注；再分别发第三、第四、第五张明牌，每张后下注，共四轮。玩家始终能看自己的暗牌；AI 暗牌只在摊牌时揭开。弃牌结束不展示对方暗牌。
4. 每轮由明牌组合较大者先行动。只比较高牌、对子、两对、三条、四条，不计算不完整的顺子或同花。组合、踢脚牌相同则由本手庄位先行动；庄位每手在玩家和 AI 间轮换，首手玩家为庄。花色不参与大小比较。
5. 不设 bring-in。可以过牌、下注、跟注、加注、弃牌。每轮第一次完整下注至少 10；之后完整加注幅度至少为上一完整下注/加注幅度。按钮“下注至”表示本轮累计投入目标，而非本次新增金额；同时显示本次再投入金额。
6. 每次下注上限：双方“本轮已投入 + 剩余筹码”的较小值。未被对手覆盖的筹码留在原账户，没有边池。封顶下注允许不足最小幅度；由于此时对手无法再加注，不存在多人桌的短加注重新开放问题。
7. 双方本轮投入相等且均完成行动，才结束该轮。双方过牌即继续发牌。有效全下获跟注后自动逐张发完余下明牌。弃牌立即将底池给对手。
8. 五张牌排名：同花顺 > 四条 > 葫芦 > 同花 > 顺子 > 三条 > 两对 > 一对 > 高牌。相同类别按组合点数、踢脚牌逐项比较；A 可作 A2345 的低端（5 高顺子），不可绕回组成 QKA23。相同牌力平分，假设出现奇数筹码则给本手庄位。双方贡献对称的当前规则下，实际平分底池为偶数。

与常见规则的偏离：无强制 bring-in；不限注额度但遵循最小完整加注；明牌平手按轮换庄位而非花色；有效筹码封顶替代边池；固定十手比赛。

## AI 与复盘边界

`engine.ts` 的 `view(game, seat)` 是唯一 AI 输入边界，含 AI 自己当前牌、对手已展示明牌、公共下注、筹码与底池。`decide(view, difficulty, rng)` 不接受 Game、牌库或对手暗牌，因此不可能通过该接口获得真实发牌顺序。

- 未知牌从剩余未知 52 张集合中均匀无放回采样，补齐双方五张牌，再比较牌力。平局计半份权益。并未根据对手过往下注推断牌型范围。
- 轻松 AI：120 次模拟、较大权益判断噪声和较高试探频率。
- 标准 AI：500 次模拟、较小噪声，按权益/底池赔率、底池尺度与少量诈唬选择行动。
- 玩家赛后快照：在其点击行动时用 240 次模拟记录，不在牌局中展示估计数值。只使用行动前可见信息，不利用最终摊牌进行“事后正确答案”判断。
- AI 复盘显示它当时自己的估计，和玩家估计可能不同，因为各自暗牌不同。所有复盘只在单手结束后展示。
- 这些是蒙特卡洛近似与启发式策略，不是 GTO 或最优策略，不提供真实金钱赌博建议。采样误差、均匀未知牌假设和简化风险模型都会影响估计。
- 发牌用 Crypto API 随机源（不可用时回退 Math.random）执行 Fisher–Yates 洗牌；难度与胜负不改变牌库，没有保底、追赶或暗中控牌机制。

## 交互、安全与存档

- 每个引擎动作必须匹配当前行动方和 revision；重复点击、旧计时回调均被拒绝。UI 同时使用同步当前状态引用阻止同一渲染帧的重复提交。
- AI 思考延时 850ms、逐轮发牌延时 650ms；“跳过等待”缩短到 40ms。离开页面、手动暂停或打开弹窗会停下游戏计时，返回后重新开始等待，不追赶执行积压动作。
- 计时器、键盘与页面监听在卸载时清理。每个组件拥有自己的音频实例和上下文。
- C = 过牌/跟注，F = 弃牌；默认只有焦点位于该组件内才响应。输入框、重复按键、组合键与弹窗期间不触发游戏动作。
- 弹窗有 Escape 关闭、Tab 焦点约束与关闭后的焦点恢复；两手之间才可切换 AI 难度；新对局需要确认。
- `prefers-reduced-motion` 关闭视觉动效。布局适配 320px 起的手机宽度。
- 存档键继续使用 `velvet-stud-v1`，内容升级为 v2 完整牌局快照。校验牌张唯一性、完整牌库、阶段、下注、整数范围与筹码总数 1000；兼容迁移旧 v1 边界存档。损坏数据被忽略，存储失败显示明确警告且不阻止游戏。
- 中途刷新精确保留暗牌、明牌、原牌序、底池、轮次与行动记录；恢复后自动暂停，点击“继续对局”才恢复计时，不重复扣底注或执行 AI 动作。完整牌局保存在浏览器本地，包含未公开牌；这不是防作弊系统，也不用于竞争性排名。AI 接口仍只能读取公开投影，完全未更改。
- 有效全下先展示本次投入和剩余筹码，确认后执行；Escape、点遮罩或“返回调整”取消，取消不扣筹码，恢复原按钮焦点。普通下注保持单步。
- 显示跟注还需金额、跟注后余额和底池、最近一次牌局动作。封顶/半池/满池快捷按钮保持合法额度；移动端主要按钮与快捷选额至少 44px 触控高度。
- 保存难度、节奏与音量。音乐/音效每次加载都关闭，必须由用户点击后开启，避免自动播放。`persist={false}` 完全不读写存储，适用于嵌入、多实例或由宿主管理存档。

## 音频

原创 A 小调、72 BPM、16 小节约 53.3 秒循环主题，使用 Web Audio 合成柔和旋律、和声与低音；不是外部录音或引用曲目。音乐与音效分别开关、调音量。页面隐藏时自动暂停，卸载停止并释放节点。启动失败显示提示且保持关闭。详见 `AUDIO-CREDITS.zh-CN.md`。

## 接入个人网站

```tsx
import { StudGame } from './stud/src/StudGame';
// StudGame.tsx 已导入作用域 CSS。
<StudGame
  persist={false}
  globalKeyboard={false}
  onExit={() => setCurrentGame(null)}
  onComplete={({score, hands, won}) => console.log({score, hands, won})}
/>
```

接口：

- `onExit?: () => void`：显示返回按钮；回调交给宿主决定路由/卸载。默认不显示。
- `onComplete?: ({ score: number; hands: number; won: boolean }) => void`：十手或破产结束后调用一次。score 是玩家最终筹码，won 为筹码大于 500。平局 won=false。
- `persist?: boolean`：默认 true，内部完整牌局存档；嵌入建议 false。
- `className?: string`：附加于根 `.stud-game`，便于调整宿主布局。
- `globalKeyboard?: boolean`：默认 false，避免干扰宿主快捷键。

组件无 `createRoot` 副作用：仅独立入口 `main.tsx` 挂载 React。接入网站时复用宿主 React，不要载入独立产物第二份 React。CSS 样式以 `.stud-game` / `.st-*` 作用域命名，无 body 或全局元素重置；宿主可以覆盖 `.stud-game { min-height: ...; padding: ... }`。
