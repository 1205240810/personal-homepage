# 三款小游戏 · 原创程序化音频

本模块的乐谱、旋律、和声及合成音色为本次项目原创程序化音频。全部声音通过浏览器 Web Audio API 实时合成；没有使用外部音乐曲目、录音、音频素材包或受版权保护的现成旋律，不涉及第三方音乐授权声明。可离线运行，无音频网络请求。

## 三首循环主题

- 数独《格间微光》：C 大调，76 BPM，16 小节，约 50.5 秒。留白较多的上行问句与下行回答，温和低音与长音和弦伴奏。
- Yahtzee《骰边小步》：D 大调，88 BPM，16 小节，约 43.6 秒。轻盈三和弦动机，后半段变化后回归主和弦。
- 五张梭哈《夜桌余韵》：A 小调，72 BPM，16 小节，约 53.3 秒。安静的低音、短小旋律及带导音的属和弦，适合牌桌节奏。

乐谱完整列在 audio.ts 的 AUDIO_SCORES 中：每一行 melody 对应 4 拍，null 表示休止；chords 和 bass 逐小节排列。基础音色为柔和正弦波，旋律附有极轻的八度泛音。音效也为原创短音型：点击、发牌、掷骰、正确、错误、胜利。

## 接入

复制 audio.ts 至游戏源目录，使用 createAudio('sudoku' | 'yahtzee' | 'stud') 创建实例。每个游戏有自己的 AudioContext，不共享全局音频状态。

音乐与音效默认均关闭；首次开启时必须在按钮点击/键盘操作回调内调用 await audio.start()，成功后再 setMusicEnabled(true) 或 setSfxEnabled(true)。start() 返回 false 时显示“当前浏览器无法播放音频，游戏可继续”，不要阻断游戏或保留虚假的开启状态。

音量为 0–1，music 默认 0.28，sfx 默认 0.35。音量设置不代表开启音频。play(event) 支持 tap、success、error、roll、card、win。pause()/suspend() 停止音频并记住用户设置；resume() 恢复已由用户启动的实例。关闭页面/卸载组件调用 dispose()。React 严格模式应在 effect 内创建实例、清理时释放，而不是复用已释放实例。

模块自行处理页面隐藏：停止定时调度并暂停上下文；恢复可见时只有用户已启用且没有主动暂停才会恢复。浏览器仍可能要求再次点击开启，不能保证后台音频播放。淡入淡出约 45 毫秒，音符有独立软包络，最多 96 个同时跟踪的声部，50 毫秒调度间隔、180 毫秒前瞻，计时受限后不会补播历史积压。dispose 清除定时器、监听器、节点并关闭上下文。

## 检查

在本目录执行 `npm run typecheck` 与 `npm test`。`src/audio.test.ts` 覆盖手势授权、单实例调度、防积压、隐藏与主动暂停、资源释放及设备异常；`src/ui-audio.test.tsx` 检查桌边开关、音量、暂停与弹窗配合。模拟测试验证控制逻辑，并不代替真机音质检查。
