# 九间 · 数独练习室

独立中文数独游戏。米白纸面与松绿色棋盘，触屏 / 键盘皆可操作。题目和音乐均在本地，无外链资源、服务器或 API。

## 直接玩

双击 `九间数独.html`，浏览器即可运行。该文件包含 React、样式、题库和原创 Web Audio 音乐，不需要联网。

使用 Node.js 20.19+ 或 22.12+：

```sh
npm ci
npm test
npm run verify:bank
npm run build:portable
npm run test:portable
npm run dev
```

依赖固定于 package-lock.json。React 19.2.6 / TypeScript 5.9.3 / Vite 7.1.9。

## 操作

- 点选格子后，点下方 1–9 或按数字键填写；给定数字无法修改。
- `N` 切换手动笔记；`Backspace` / `Delete` / `0` 擦除。
- 方向键移动；`Ctrl/⌘ Z` 撤销；`Ctrl/⌘ Shift Z` 重做。
- 撤销保留最多 200 步；存档恢复当前棋盘、笔记和用时，不恢复历史栈。
- 「显示合法候选」是计算出的候选覆盖层；关闭后仍保留自己的手动笔记。
- 教练默认开启，但不会自动填数；必须按「应用这一步」才改变棋盘。
- 新题有确认窗口；三档各 40 题，共 120 题。题库支持按难度、已完成 / 未完成筛选和指定选题；随机优先未玩过的题目，并避开当前题。完成记录保存在本机。
- 背景音乐、操作音效分别默认关闭；均有独立音量。浏览器不支持音频时有明确提示。
- 暂停、切到后台和打开模态窗口都会停止计时；暂停和后台暂时隐藏棋盘。

## 教练的逻辑边界

支持三种可解释的人类技巧：

1. 唯一候选：当前格只有一个合法数字。
2. 单元唯一位置：行 / 列 / 宫内，某个数字只可能放在一格。
3. 宫内锁定候选：宫内某个数字的全部候选都落在同一行 / 列，排除该行 / 列在宫外的同数字候选。

教练用当前棋盘及已经确认的候选排除推导，展示目标、依据与所在单元。单元唯一位置若依赖前面的排除步骤，会明确列出这些格子并高亮依据。宫内锁定只排除候选，不假装已经确定某个数字。

- 直接重复：标红冲突格，停止提供推理。
- 没有重复但整体无解：用回溯检查确认「当前已填数字无法组成完整解」，提示检查输入，不把某个预存答案当作证明。
- 没有支持的推理：明确说明未找到支持的技巧，不猜测、不静默调用答案。
- 项目不存储题目答案。回溯求解器仅用于生成时唯一性验证、运行时整体可满足性检查、测试时反证。

### 题库与分级

原始 15 题的 ID、题面、分级保持不变，存档可继续使用。`scripts/legacy-puzzles.json` 固定这部分兼容数据。`npm run generate` 用种子 `2026100802`，通过随机回溯从空棋盘构造新的完整盘面，再逐格移除线索生成另外 105 题；不是将同一题换数字或旋转来扩充。每次移除都要求恰有一个解，最终每题再次验证。此次确定性生成用了 482 次尝试。测试同时检查 120 道线索布局在旋转 / 镜像下不重复。

40 道入门只需唯一候选；40 道进阶需要单元唯一位置；40 道挑战需要宫内锁定候选。分级指本实现固定扫描顺序的逻辑求解路径，非宣称跨平台统一难度。所有 120 道题都能用上述技巧完全解出，生成时拒绝逻辑求解停滞的题目。每题附 clues 与完整分级统计，测试重算校验。题目有唯一解，不意味着任意错误输入仍有解。

### 存档安全

本机 localStorage 键 `nine-rooms:sudoku:v1`，格式版本 1。恢复时验证题号、数组形状、数字范围、给定数字和用时；损坏存档安全回退。恢复时丢弃缓存的候选排除，重新从棋盘推理，防止被修改的排除数充当证明。浏览器禁止存储会显示提示。无数据上传。

题库记录另存于 `nine-rooms:sudoku:progress:v1`，格式版本 1：记录玩过的题号、已完成题目的用时与是否使用教练。未知题号或损坏记录被过滤；首次升级会从旧版当前存档导入状态，已完成的旧局会计入进度。当前棋盘仍沿用原有存档键及格式，扩充题库不会清空正在玩的题。换题前若已有填写、笔记、排除或用时，会再次确认；取消或 Esc 均保留当前局。

## 嵌入现有 React 网站

复制 `src/SudokuGame.tsx`、`src/logic.ts`、`src/storage.ts`、`src/progress.ts`、`src/puzzles.json`、`src/audio.ts`、`src/sudoku.css` 到现有项目。复用宿主 React，不复制 standalone 的 `main.tsx` 或第二份 React。

```tsx
import { SudokuGame } from './sudoku/SudokuGame';

<SudokuGame
  onExit={() => setScreen('home')}
  onComplete={({ puzzleId, seconds, assisted }) => console.log(puzzleId, seconds, assisted)}
  persist={true}
  globalKeyboard={false}
  className="my-game-container"
/>
```

- `onExit`：可选，提供后显示退出按钮。
- `onComplete`：当前题目会话首次完成时回调，撤销 / 重做不会重复发出。宿主若需要跨刷新全局去重，应按自己的比赛或会话 ID 处理。
- `persist`：默认 true；同源使用单个存档键，多实例嵌入请设 false 或自行扩展独立 key。
- `globalKeyboard`：默认 false，只处理组件内焦点事件；独立 HTML 开 true。嵌入时不建议全局开启。
- `className`：附加根类。组件所有样式以 `sg` / `sg-` 命名，不重置宿主 body、button 或其他全局元素。
- 音频引擎每实例独立，在挂载 effect 建立、卸载 dispose，兼容 StrictMode。
- 模态窗口有 Tab 焦点循环、Escape 关闭、返回原按钮，并将底层内容设 inert。
- 无 SSR 依赖要求：渲染时存储读有保护，浏览器专属事件只在 effect 内建立。

## 验证与限制

- 141 个逻辑 / 题库 / 存档测试：120 道题逐题验证唯一解、准确分级、完整推理链，以及每个填数 / 排除步骤的反证；锁定候选额外验证同宫同线与宫外目标。旧题数据逐字段保持一致。
- `npm run verify:bank` 用独立位掩码求解器再次验证全题库唯一性，不导入生产求解器。
- 24 个 React DOM 回归测试：触摸、笔记、键盘隔离、撤销重做、显式应用、暂停、新题取消、焦点循环、存档恢复、完成回调、错误但无重复的输入、辅助记录跨刷新保持、选题筛选、已完成记录、随机题、换题二次确认、空操作不增加撤销步数、方向键边界及系统快捷键保护。
- 20 个题库记录 / 选题策略测试：损坏与未知版本处理、旧局迁移、已玩和已完成状态、筛选、随机优先未玩及避开当前题。
- 修订版通过 `npm ci` 从固定 lockfile 和 npm 缓存安装 116 个包，不依赖共享 node_modules。完整测试、类型检查、生产构建与便携包挂载结果见本次交付记录。
- `npm run build:portable` 包括严格 TypeScript 类型检查和 Vite 生产构建。
- `npm run test:portable` 在 JSDOM 挂载内联发布文件，确认 81 格与默认静音、无外部脚本 / 样式资源。
- 本环境未完成真实浏览器截图、实际扬声器听音或真实手机触摸验证；JSDOM 不能替代像素、浏览器音频和设备测试。
- 适配 320px 起，桌面双栏、手机单栏，支持 prefers-reduced-motion。
- 原创曲目说明见 `AUDIO-CREDITS.zh-CN.md`。没有使用商业录音或外部音乐。
