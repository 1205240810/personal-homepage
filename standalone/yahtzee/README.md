# 快艇骰子 · 蓝调骰子会所

独立中文 Yahtzee 玩家对 AI 游戏。原创海军蓝/象牙白/黄铜视觉、CSS 九宫骰面与合成器配乐；无外部字体、图片、广告、账号或真钱机制。

## 直接运行

打开 `快艇骰子.html` 即可离线游玩，不需要网络或安装。桌面浏览器和手机均可。首次使用音乐、音效均关闭，需要在设置内主动开启。浏览器文件模式或无痕模式可能不允许存档；界面会提示，仍可游玩。

源码运行：

```sh
npm ci
npm test
npm run dev
npm run build:portable
```

React 19.2.6、React DOM 19.2.6、TypeScript 5.9.3、Vite 7.3.7、Vitest 4.1.11；所有直接依赖固定版本，附 package-lock.json。Node 建议 22.12+。独立 Vite/Vitest 配置不会读取宿主网站配置。`npm run build` 包含严格类型检查。构建前自动用 esbuild 打包 AI worker，单文件版通过 Blob worker 运行，无独立资源请求。

## 玩法

- 你先手，与蓝调轮流行动，各填完十三个分栏后比较总分，允许平局。
- 每回合五骰最多三掷；首次全掷，后续点选骰子保留。可提前在分栏上记分。正分先选择、再在该栏下方确认；填零另有警告，避免误触。
- 每栏仅用一次；虚线与“预览”标识表示尚未记入，粗体为已记分。改动骰子或重新投掷会清除待确认的选择。
- 一至六点：对应骰子之和。上区总分至少 63，另奖 35。
- 三条/四条：至少三/四骰相同，得全部五骰总和。
- 葫芦：三同加二同，25。小顺：至少四种连续点数，30。大顺：五种连续点数，40。
- 快艇：五骰相同，50。全选：五骰总和。
- 已填快艇栏后再次五同：强制填对应的上区；该栏已填，必须选择尚空的下区，葫芦/小顺/大顺可按 Joker 取得固定分；上下相应栏和全部下区都已满，才能选择其余上区填零。
- 原快艇栏为 50 时，重复五同另加 100；原栏为零也适用 Joker，但没有 100 奖励。奖金在记分时一次性结算。

依据 Hasbro 官方说明，并以其 FAQ 的 Joker 明确口径实现：
- https://www.hasbro.com/common/instruct/yahtzee.pdf
- https://hasbro-new.custhelp.com/app/answers/detail/a_id/211/

这是独立原创实现，未使用 Hasbro 美术或音频，也非官方产品。

## AI 的能力与边界

- 决策只读取自己的当前骰子、未填分栏、上区进度与难度，不读取未来随机数。双方投掷均独立使用标准六面骰分布，无作弊或追赶机制。
- 所有保留子集逐一评估，对下一次重掷的计数分布进行精确概率枚举（多项式权重），相同点数的保留组合去重。
- 轻松档最大化眼前分数；标准档在此基础上减去分栏机会成本，并按上区奖励差额施加启发式价值。
- 即使还有两次重掷，也使用单步前瞻；没有计算整局、两次连贯前瞻或对手分差策略。标准档是“长期启发式”，不是全局最优，亦不保证每局都强于轻松档。
- 浏览器支持时在独立 worker 计算。CSP/worker 不支持时，每四种保留策略让出主线程的协作式计算，算法不降级。4 秒 worker 未应答后使用同策略备用路径。暂停、重开和卸载取消结果。
- Worker 消息必须为五个布尔保留位和有限期望值；损坏消息、反序列化失败与超时进入同算法 fallback，迟到结果不再应用。fallback 固化请求时的骰子与分栏，不随调用方的后续修改变化。若备用计算本身意外失败，明确提示本回合按当前合法最优分栏记分，不将其冒充完整重掷策略。
- 桌边设置可开启快速 AI 节奏，仅缩短动作间隔（850ms → 120ms），不改变计算、难度或随机结果。
- 对手每次行动后解释保留/记分理由，玩家可赛后查看真实记分轨迹；此记录不宣称每步最优。

## 嵌入个人网站

```tsx
import { YahtzeeGame } from './yahtzee/YahtzeeGame';

<YahtzeeGame
  persist={true}
  globalKeyboard={false}
  onExit={() => navigate('/games')}
  onComplete={({ player, ai, winner }) => console.log(player, ai, winner)}
/>
```

复制 `src` 内除 main.tsx 与测试外的文件至宿主项目。保留 styles.css、audio.ts、ai.ts、logic.ts、worker-source.ts；worker-source.ts 已提交，可直接集成。修改 AI 逻辑后用 `node scripts/build-worker.mjs` 重新生成。不要嵌入 main.tsx 中的 createRoot，也不要装第二份 React。宿主复用 React 19。

API：
- `onExit?: () => void`：出现返回按钮，点击先暂停，再通知宿主。
- `onComplete?: ({player:number, ai:number, winner:'player'|'ai'|'draw'}) => void`：当前挂载期间每个对局 ID 通知一次。重新挂载已结束的存档会再次通知，宿主若用于记账应自行幂等；这不是金钱或排行榜结算接口。
- `persist?: boolean`：默认 true。localStorage 键 `blue-dice:v1`，保存分栏、骰子、保留状态、回合、难度、结果日志；刷新后未结束的对局暂停等待“继续”，不会让 AI 自行推进。兼容原 v1 存档，并拒绝不可能的奖励、非法分数和损坏内容；无法读写时降级。不保存音频开启状态，避免自动播放。
- `className?: string`：宿主附加样式类。
- `globalKeyboard?: boolean`：默认 false，仅在组件内部非交互控件聚焦时响应空格、1–5。嵌入推荐保持 false；不拦截表单、按钮或链接键盘事件。

全部 CSS 选择器使用 `.yd-game` 根作用域，动画名使用 yd- 前缀；320px 宽单列不裁切分栏。支持 prefers-reduced-motion，骰面提供读屏标签与保留状态，弹窗约束焦点并支持 Escape。切后台自动暂停，回到前台需继续。SSR 首次渲染不读 localStorage，挂载后先恢复再允许写存档，避免 hydration 不一致和新空局覆盖旧进度。

同时提供 `default export YahtzeeGame` 和命名导出。`onExit` 会立即暂停音频与迟到 AI 提交，再通知宿主；不操作宿主路由或窗口。键盘忽略输入法、原生设置 summary、可编辑文本和嵌套按钮图标，保持宿主控件自己的操作。
