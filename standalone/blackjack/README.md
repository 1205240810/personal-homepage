# 暗牌 21：标准练习与休闲牌桌

中文单人 Blackjack 游戏，默认进入标准规则练习：可自定义虚拟筹码和下注，支持加倍、分牌、晚投降、保险、3:2 天然结算，以及分步新手教程和赛后教练。原有经典积分与策略庄家保留在「休闲对局」。

本站已原生集成到 [暗牌 21](https://tscjj.com/games/blackjack)。源码在此目录维护，构建前同步到宿主，不使用 iframe 或第二份 React。技术栈为 TypeScript、React 19.2.6、Vite；所有数据在浏览器本地，不涉及真实资金或支付。

## 开发与构建

要求 Node.js 22.12+，依赖由 package-lock.json 锁定。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
# 可选：生成自包含 HTML 并检查旧休闲 Worker
npm run build:portable
npm run test:portable
```

独立开发页默认 `http://localhost:5173`。构建输出到 `dist/`，便携打包生成 `暗牌21.html`。dev/test/build 前重新生成原有教练的 `src/coachWorkerSource.ts`，不应手工编辑。浏览器对 file:// 存储和 Blob Worker 的限制可能与 HTTP 不同，便携包测试不代替网站视觉验收。

## 固定的标准桌规

- 六副 52 张牌，每局重洗；不做跨局牌靴或算牌训练。
- 玩家先行动，庄家固定执行 S17：不足 17 要牌，所有 17 和更高点数停牌，包括 A+6。庄家不能针对玩家终值改变操作。
- 原始两张 A + 10 点牌是天然 Blackjack，赢时净获下注的 1.5 倍；双方天然平局。分牌后得到 21 只按普通 21 结算。
- 庄家明 A 时先提供保险，然后检查暗牌；明 10 时直接检查。庄家排除天然后才开始玩家普通操作。
- 初始两张牌可加倍下注，追加同额筹码，只再拿一张牌，然后自动停牌；分牌后也可加倍。
- 同点数两张牌可分牌，追加同额筹码；最多四手。分 A 每手仅拿一张，不可再分 A。
- 晚投降仅限未行动的原始两张牌，退回一半下注；分牌后不能投降。
- 保险金额为原注的一半，庄家天然时净获保险下注的两倍，否则损失保险注。保险与主注独立结算。
- 每手赢净获一倍，平局退回下注，爆牌先输；分手分别结算。没有五张牌自动获胜等额外规则。

初始金额为 100–1,000,000 的正偶数，下注为不少于 2 的正偶数。余额允许结算后出现奇数。所有追加操作都校验可用筹码；改下一局下注不重置资金，重新设初始筹码则明确重开练习。遇到异常无牌可发时整局作废、返还所有下注。

规则依据：[Blackjack rules](https://wizardofodds.com/games/blackjack/basics/)。不同赌场使用不同的牌数、软 17 与分牌限制；本游戏只实现这里明确的一套。

## 标准赛后教练

教练只使用决策时的公共快照：手牌、庄家明牌、公开牌、资金与分牌限制。不读暗牌、真实牌序、随机种子或后来揭示的结果。分析比较所有当时合法操作，以当前这手下注为单位给出期望净收益，并解释实际选择与推荐的差距。

标准模型采用独立抽牌动态规划，明确标为近似；它不等同于六副真实牌组不放回的精确解，不宣称固定胜率或通用 GTO。加倍与分牌收益按实际追加风险计算，晚投降为 −0.5 单位。分牌的资源和跨手近似见 `SOLVER-NOTES.md`。收益差是长期平均意义，不能直接解释成这局本该赢的钱。

教程可随时重看，说明软/硬点数、天然、固定庄家、加倍、分牌、投降、保险及期望收益；推荐先读教程再上桌，也可直接开局。

## 休闲模式

旧经典模式与策略庄家仍使用单副牌，每局洗牌，只要牌/停牌，胜 +1、平 0、负 −1；天然无额外奖励。

经典庄家固定 S17。策略庄家看见玩家最终手牌后最大化自己的期望积分，有后手信息优势；不是标准赌场庄家。它不读未来牌序。休闲教练默认关闭，仍在 Worker 中做有限牌组求解，超预算则整体回退到独立抽牌近似，方法明确标注。

## 存储与生命周期

标准记录使用 `twenty-one:standard:v1`，与原 `twenty-one:v2` 完全分开。只存完整结算后的资金和设置，不恢复未完成局。刷新未完成局回到上一份结算快照，不重复扣除下注。存储不可用时当前页面仍能练习。

游戏快捷键仅在牌桌内生效，对话框和输入框不响应出牌。切到后台暂停发牌及庄家定时行动，回来可继续。音效默认关闭，系统减少动态效果设置生效。退出清理定时器、监听、音频及休闲教练 Worker。

## 接入现有 React 项目

```tsx
import { BlackjackLobby } from './BlackjackLobby';

export function GameRoom() {
  return <BlackjackLobby persist onExit={() => window.location.assign('/games')} />;
}
```

`BlackjackLobby` 默认标准模式并提供休闲入口，局中不可切换。直接挂载 `StandardBlackjackGame` 可只显示标准玩法；`BlackjackGame` 仍是原休闲组件。CSS 使用 `bj-` 或 `sbj-` 前缀。复用宿主 React，不加载独立 dist 中的第二份运行时。

本站运行文件同步与发布验证见 [BLACKJACK.md](../../docs/BLACKJACK.md)。修改 src 后在仓库根目录执行：

```sh
node scripts/sync-blackjack.mjs
npm run check
npm run build:node
```

标准纯规则、教练数学与 UI 交互都通过各自测试验证；实际验收记录见 `qa/VERIFICATION.md`。纯前端状态可被开发者工具检查，信息隔离指教练的决策接口，不是联网反作弊。
