# 随机开屏与手机适配

## 开屏

- 四张原画：墨绿探索型、钴蓝导航型、旧铜检修型、石墨勘探型。
- `lib/arrival-art.ts` 维护资产、替代文本与独立的横竖屏取景。
- `/` 每次服务端请求随机选一张，把同一数据交给 React；不在 hydration 后改图、不自动轮播、不预加载整套。
- WebP 质量 84、原始 1672 × 941 分辨率，四图分别 181698 / 234146 / 271634 / 189244 字节。生成提示词与 PNG 来源保留在 design 目录。
- 12 次本机请求观察到四个资源均被选中：导航 2 / 检修 5 / 墨绿 1 / 勘探 4。随机允许连续重复。

## 手机操作

- 工作台文章在先；项目选项卡保留两个示例，默认摘要，展开后运行原有演示。桌面自动展示完整演示。
- 输入框 44px / 16px，开屏音乐与检修灯按钮 44px；文章 pre/code 最终 14px，正文 16px。
- 目录子项按自然高度滚动，防止多行标签被 Flex 压缩。手机主题筛选按需展开，选中后收起；关闭栏固定。
- 探索保留点击物件自动寻路；手机菜单与方向盘折叠，竖屏为画布腾出操作空间，横屏仍可展开方向盘。地图坐标、碰撞和角色控制算法不变。
- 当前场景的暗化模糊背景延伸到画布外；处理 safe-area，不强制横屏，也不禁用页面缩放。

## 核对记录

浏览器视口 390×844、375×667、844×390、1280×800。手机两项目的展开/收起、主题筛选、文章读取/关闭、菜单、横屏方向盘可用；标签区与第一篇文章无重叠。实测代码字号 14px、输入框 44px / 16px、开屏三个辅助按钮均 44×44px。桌面项目和文章保持左右布局。阅读与工作台未发现整页横向溢出。
