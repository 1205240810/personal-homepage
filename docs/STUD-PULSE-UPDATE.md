# 梭哈复盘与三十关灯阵

2026-10-09 更新，基于已上线的八款游戏版本。保留所有路由、梭哈固定双人规则和原十二关存档。

## 梭哈

- 余额、本轮投入、底池分配和净变动分开显示；下注区说明累计总额、本次新增投入、下注后余额与有效封顶。
- 桌边可直接开启原创《夜桌余韵》并调音量，默认静音；暂停、弹窗、隐藏和卸载管理音频资源。
- 公开明牌与动作软修正合法暗牌范围，无放回补齐五张牌；共用样本比较跟注、弃牌和多个合法尺度。深筹码提前轮次避免默认巨额全下，免费过牌不推荐弃牌。
- 赛后逐次展示实际选择、稳健参照、当时牌面、跟注成本、理由、替代尺度和下一步。弃牌仍不公开 AI 暗牌或其私人牌面分析。旧记录没有新字段时保留原数据，不补造诊断。
- 修正“对手有效全下、玩家仍待跟注或弃牌”时的存档校验，恢复不会重复扣底注。

这是公开信息范围与一轮响应的启发式近似，未搜索完整后续下注树，不能当作严格 GTO、精确行动评分或盈利保证。候选估值差距不同于实际输赢，模型偏差不同于抽样误差。具体模型和规则见 [独立源码说明](../standalone/stud/README.zh-CN.md)。

## 点灯

新增十八道五阶纹样，合计三十关、六阶段；真实最短解从一步逐渐增加到十五步。所有关卡经过可解性、最短步数及旋转/镜像去重检查，原十二关 ID、棋盘和最短解保持不变。v1 存档继续保留进度、提示、撤回和成绩，完成旧十二关后可继续第十三关。章节和总关数由同一份数据生成。
