# 暗牌 21：标准规则练习与休闲对局

线上地址为 `/games/blackjack`。从机甲游戏厅进入时带 `?from=explore`，返回链接保留来源。本站原生挂载 React 组件，共用 React 19.2.6；没有 iframe 或第二份 React。

## 标准规则

默认进入标准练习，所有筹码均为浏览器本地虚拟数据。采用一套固定桌规，避免建议和实际结算使用不同规则：

| 项目           | 实现                                                                  |
| -------------- | --------------------------------------------------------------------- |
| 牌组           | 六副 52 张牌，每局重新洗牌；不模拟跨局牌靴或算牌                      |
| 庄家           | S17：不足 17 必须要牌，所有 17 及以上停牌，包括软 17                  |
| 天然 Blackjack | 原始两张 A + 10 点牌；赢时净获下注的 1.5 倍，即 3:2；双方天然平局     |
| 检查暗牌       | 明牌 A 时先提供保险选择再检查；明牌 10 时先检查天然                   |
| 加倍           | 两张牌时追加等额下注，恰好再发一张，随后自动停牌；允许分牌后加倍      |
| 分牌           | 两张同点数牌可拆为两手并追加等额下注，最多四手                        |
| 分 A           | 每手只再发一张，不能再次分 A；分牌后的 21 不算天然                    |
| 晚投降         | 庄家排除天然后、原始两张牌尚未行动时可用；退还一半下注                |
| 保险           | 庄家明 A 时可用，下注为原注的一半；庄家天然时净赔 2:1，独立于主注结算 |
| 普通结算       | 赢净获 1 倍，平局返还下注，爆牌先输；各分手分别结算                   |

庄家没有自主决策空间，状态机内部强制执行 S17，不会因玩家点数更高就追牌，也不依赖传入的行动。标准规则不使用休闲模式的「策略庄家」。

初始筹码和每局下注可设置。初始金额与下注使用正偶数，便于一半下注和 3:2 结算；结算余额可以为奇数。修改下一局下注保留余额，重新设置初始资金则明确重开练习。加倍、分牌和保险都要求当前可用筹码足够。开局扣除托管下注，结束按每手结果返还；异常耗尽时整局作废并退回所有本局下注。

## 新手教程与复盘

牌桌上方的「桌规与入门提示」默认收起，可用键盘展开；「新手教程」始终保留在操作栏。手机上筹码汇总合并为一行，庄家展示缩短，把自己的手牌和对局操作留在更近的位置。

教程通过分步例子解释 A 的软硬点数、庄家固定规则、天然与普通 21 的区别、加倍、分牌、投降、保险及收益概念。可随时重新打开，不强制先完成教程才能开局。对话框支持键盘关闭、焦点管理及小屏滚动。

标准教练保存每次决策时的公共快照：当时手牌、庄家明牌、已公开牌、分牌状态、资金限制和合法操作。不会保存或读取暗牌、牌堆顺序或随机种子；不能用结算后的牌倒推历史建议。分析比较合法操作的期望净收益，单位为该手当前下注。收益差乘下注得到预计筹码损失，不是该次实际输赢，也不是胜率。

标准教练采用独立抽牌近似：在明确桌规下递推要牌、停牌、加倍与分牌等动作。它不是六副牌不放回的精确求解器；分牌和资金模型的具体近似随结果提示，详见 [求解说明](../standalone/blackjack/SOLVER-NOTES.md)。界面显示方法、推荐操作、实际操作、收益差及中文原因。教练建议不保证单局获胜。

## 保留的休闲玩法

「休闲对局」保留原始经典与策略庄家两种玩法：单副牌每局重洗，只做要牌和停牌，胜 +1、平 0、负 −1，不使用虚拟筹码或天然额外赔付。策略庄家在玩家结束后利用其最终手牌选择行动，有后手信息优势。原教练仍使用有限单副牌模型，超预算后整体切换独立抽牌近似。

标准记录使用独立键 `twenty-one:standard:v1`，旧休闲记录 `twenty-one:v2` 不会被修改或混合。只持久化完整结算后的资金，不恢复未完成对局；刷新未完成局回到上一份结算快照。存储被禁止时可继续在当前页面练习。

## Hi-Lo 记牌练习（可选）

大厅第三个标签「记牌练习」是独立的计数训练，不改变标准牌桌：标准规则仍每局重洗六副牌，计数对结果没有作用。练习使用 1 / 2 / 6 副牌靴并跨轮延续，按手动或 1.5 / 0.9 / 0.5 秒自动翻牌，每轮 10 / 20 / 30 张后报出 Hi-Lo 流水数（2–6 记 +1，7–9 记 0，10 / 人头 / A 记 −1）。结果页给出按半副估算剩余牌后的真数、本轮每张牌的计数值和净变化；新手可在牌下显示计数值。答对次数与连对记录保存在 `twenty-one:hilo:v1`，存储不可用时仍可练习。规则在 `standalone/blackjack/src/hilo.ts`，界面在 `HiLoTrainer.tsx`。

## 手机操作栏

窄屏（≤ 600px）下标准牌桌的状态与操作区固定在屏幕底部，开始对局、要牌、停牌等按钮无需滚过牌桌即可点击；德州扑克练习桌（≤ 700px）的开始与下注区同样固定在底部，并为全面屏留出安全区。

## 单一源码与同步

维护源在 `standalone/blackjack/src/`。`scripts/sync-blackjack.mjs` 将运行源码同步到 `components/games/blackjack/generated/`，不要直接修改生成目录。

- `BlackjackLobby.tsx`：标准 / 休闲入口，局中禁切换。
- `standardTypes.ts`：唯一标准桌规与公共快照契约。
- `standardGame.ts`：纯状态机、筹码账本、固定庄家、合法操作。
- `standardSolver.ts`：只读公共快照的标准期望收益教练。
- `StandardBlackjackGame.tsx`：牌桌、设置、教程、复盘和本地记录。
- `game.ts`、`solver.ts`、`BlackjackGame.tsx`：原有休闲模式。

```sh
npm --prefix standalone/blackjack ci
npm --prefix standalone/blackjack run typecheck
npm --prefix standalone/blackjack test
npm --prefix standalone/blackjack run build
node scripts/sync-blackjack.mjs
node scripts/sync-blackjack.mjs --check
npm run check
npm run build:node
```

修改旧 `coach.worker.ts` / `solver.ts` 后，独立项目 build/test 会重新生成 `coachWorkerSource.ts`。标准教练与原有休闲 Worker 是不同模型；不要混用。

宿主 hydration 后按需挂载入口，避免 localStorage 导致首屏不一致。退出使用整页导航，释放定时器、音频和原有教练 Worker。标准模式切后台暂停发牌及庄家行动，操作对话框打开时也暂停，避免用户阅读时牌桌继续推进。系统减少动态效果设置生效。没有新增远端 AI 服务或修改服务器安全策略。
