浮桥初始水位为 0，上游进水阀为 0 档、旁路泄水阀为 2 档。水位 = 2 + 进水档 − 泄水档，金线为 3。每只阀依次循环 0/1/2 档，只调整一侧不能完成初始机关。对准金线后浮桥扣稳，不再落下；桥面图像升高与真实碰撞通路一起更新。桥不会关闭，不存在把玩家留在桥上或对岸的情况。

水车坡地的引水渠通向水车，工坊左侧工作台上是动力控制板。回路接通后水车转动、索道指示灯点亮；两张地图各有一个索道台，使用后回到另一侧的固定安全站位。河岸通道和索道使用不同返回点。

水岸、建筑、树干、桌椅有物理阻挡。草地可自由绕行，石路只提供方向。路边的记忆卡片、猫与旧机甲镜头都不阻挡主线。文章、档案和项目访问不检查探索进度。

新增内容通过 ContentSource 自动进入书屋。新增支路通过 SceneDefinition 的地面、图层、节点和入口连接扩建；新机关需要明确的 WorldAction 和状态规则，不添加空后台或通用插件系统。
