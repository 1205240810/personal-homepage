# 河谷漫游验收记录 · 2026-09-07

## 本轮验证

- 两张 2400×1440 的室外地图、两处按 .42 统一比例重做的室内，共24个互动节点。注册表与Tiled输出一致；有效出生点、家具脚印、可达路线、节点引用与草稿隔离均通过构建检查。
- 初始两只水阀必须共同参与调整。关桥时无法横越河道，西岸节点可达；对齐金线后桥面升起、碰撞通路开放。所有开放节点的路线逐段检查。
- Edge实测主线：开始菜单 → 沿路到进水阀 → 前往泄水阀 → 浮桥升起 → 实際步行过桥 → 沿河进入水车坡地 → 进入工坊 → 点击左侧控制板 → 12次旋转接通回路 → 索道返回河湾。
- 返回位置为 hub (475,1010)，刷新后仍保持该位置，以及 bridge=true、lift=true 和电路成绩。停步时立即保存最终坐标，修复原先存档落后于人物的现象。
- 1440×900桌面和390×844手机视口均由游戏画布填满。手机无横向溢出，触控按住能走，松手后坐标停止变化。
- 阅读面板打开期间按D不移动；关闭后坐标保持不变。系统减少动态效果时仍能从河湾进入书屋，过渡被跳过。

- 图层使用真实角色图集、独立建筑、树冠、机关、桥绳和室内家具；人物脚锚点逐帧对齐。修复住宅左墙、工坊右墙、石桌与地图边缘的具体碰撞错位。
- 河谷地图显示当前章节、桥与索道状态；文章、项目、档案的直接访问不依赖谜题完成。
