## 评分分离与全桌回放 · 2026-10-08

本节替代下文旧版评分口径；历史验收保留当时结果，不代表现有评分公式。

- 取消「先抵消误差再打分」造成的满分平台，按普通尺度数值参照的原始 EV 损失连续映射，一位小数显示。抽样接近与模型敏感性单独标注；极端尺度显示待评，不参与平均分。普通数值参照与稳健推荐分别标明，旧记录显示旧模型标识。
- 固定 1,400 次同种子 J3 / T33 局部回归：过牌估值 2.51 BB、20.6 分；加注到 20 估值 3.39 BB、66.5 分，标估值接近且为稳健推荐；到 30 估值 3.70 BB、100 分，为普通数值参照；990 巨额全下估值 3.85 BB，标估值敏感，界面不展示数分。该教学刻度未经外部 GTO 标签拟合，不能从这些分数推断真实均衡频率。
- 原 43o 回归仍推荐弃牌／过牌／弃牌／过牌；独立河牌空气跟大下注为 14.2 分，错弃私人皇家同花顺为 0.1 分。评分只使用决策当时公开快照，不依据结算输赢。
- 选择性诈唬区分纯诈唬、半诈唬、牌面相关阻挡牌及错过的听牌，压低多人触发率；全下约束明确区分主池与边池。翻牌持续下注只认翻牌前进攻者且此前无人下注。
- 全桌回放在整手结束后才生成，包含全部底牌（含弃牌者）、逐街公开行动、真实 AI 策略分支、混合抽样与跟注 EV 校正。候选 EV 是诊断，不伪称 AI 每次都执行候选最高值；全知信息不输入玩家评分。
- 新回放检查覆盖 320 手 2–9 人随机局、真实 AI 多街对局、组合听牌、短大盲、累计短全下、退款，以及错误诊断和未来公共牌拒绝。存档与生命周期探针覆盖陈旧计算、暂停取消、重复归档、跨手回放错配、2MB UTF-8 读写边界和旧记录降级。
- 正式 Node 预览实际完成五人桌五次玩家选择、四条街共二十次行动，以及九人桌玩家弃牌后的整手；核对全部底牌、按席位筛选、真实价值分支、存档刷新和五／九人记录切换。历史均分 45.4 与当前手均分 18.2 分别显示，没有串用。进行中全桌视图只显示等待提示。
- 桌面 1400×900、手机 390×844 与 320×740 的回放面板无横向溢出，键盘 Esc 正确关闭；生产预览未观察到控制台错误。完整 `npm run check` 与 `npm run build:node` 通过（牌型 7、引擎 21、回放 9、策略 24 组检查），公开内容仍为 74 篇。共享 dev 的旧预打包 React 缓存报错未用于验收，生产产物实测正常。

- 玩家与四位 AI 同桌，四种风格与入门、标准、进阶难度分离；当前手设置固定，修改在下一手生效。实际走完进阶牌局，覆盖多人入池、加注、弃牌、各街跟注与摊牌，玩家弃牌后其余席位继续行动。

## 自动检查

`npm run check` 覆盖 TypeScript、正式内容隔离、场景可达性、项目示例和游戏规则。新增牌型与扑克检查覆盖最佳五张牌、A2345、七张牌比较、按钮与盲注、加注增量、短全下、平分底池及筹码守恒。

策略检查执行 500 手固定种子自动对局，包含三种对手风格、不同筹码与两个按钮位置。代理断言阻止 AI 读取玩家底牌，也阻止复盘读取对手底牌和未来牌面；覆盖超额全下的有效风险与退款。

`npm run build:node` 成功生成独立 Node 产物。新增游戏文件的定向 oxlint 检查通过；全仓 `npm run lint` 仍有原有页面、教学案例和测试的规则错误，这次没有将其描述为通过，也没有扩大修改范围。既有 Phaser 包的构建体积提示仍存在。

## 当前范围

AI 是浏览器内的混合启发式策略，权益来自均匀随机未知对手手牌的蒙特卡洛抽样。逐手建议解释赔率、位置、下注目的与 GTO 思路，尚不提供严格均衡求解、多轮 EV 或精确动作频率，也未接入联网大模型。所有筹码都是虚拟数值。

目录、游戏路由、纯规则与 React 界面各自维护。新增游戏的步骤和规则来源见 [游戏室与扩展](GAMES.md)；线上更新、独立构建与回滚见 [服务器部署](SELF-HOSTING.md)。
