# 游戏室首版验收 · 2026-10-08

这次更新增加独立游戏室、机甲内的实体街机入口与单挑德州扑克练习桌。文章、作品和档案仍可直接访问。

## 实际验证

- 欢迎页保留两个主要入口，在下方增加游戏室；工作台导航和侧栏也可选游戏。游戏室提供两款实际可玩的游戏，不显示待开发入口。
- 桌面完整走过翻牌前、翻牌、转牌、河牌和摊牌，验证跟注与按钮位轮换；另验证全下、暂停期间不执行 AI 延迟行动、恢复后自动跑完公共牌。
- 复盘使用每次行动当时的公共牌、底池和跟注价格。弃牌或摊牌后保存记录，刷新仍保留累计统计与最近记录；进行中的对局刷新后重新开始。
- 手机检查 390 × 844 与 320 × 740：页面没有横向溢出，公共牌能完整排下，行动按钮可触控。窄屏设置与行动记录移到牌桌下方，复盘独立展开。
- 灯阵入口复用十二关；手机完成第一关，最短解、完成反馈和下一关按钮正常。
- 试作间点击街机后角色沿可达路径走近并打开游戏室，选择游戏保留来路；返回 `/explore` 后恢复试作间街机旁位置，键盘移动正常。浏览器后退也恢复试作间。
- 首屏、游戏室、牌局和机甲往返未观察到浏览器控制台错误。动效只在 `prefers-reduced-motion: no-preference` 时启用。

## 自动检查

`npm run check` 覆盖 TypeScript、正式内容隔离、场景可达性、项目示例和游戏规则。新增牌型与扑克检查覆盖最佳五张牌、A2345、七张牌比较、按钮与盲注、加注增量、短全下、平分底池及筹码守恒。

策略检查执行 500 手固定种子自动对局，包含三种对手风格、不同筹码与两个按钮位置。代理断言阻止 AI 读取玩家底牌，也阻止复盘读取对手底牌和未来牌面；覆盖超额全下的有效风险与退款。

`npm run build:node` 成功生成独立 Node 产物。新增游戏文件的定向 oxlint 检查通过；全仓 `npm run lint` 仍有原有页面、教学案例和测试的规则错误，这次没有将其描述为通过，也没有扩大修改范围。既有 Phaser 包的构建体积提示仍存在。

## 当前范围

AI 是浏览器内的混合启发式策略，权益来自均匀随机未知对手手牌的蒙特卡洛抽样。逐手建议解释赔率、位置、下注目的与 GTO 思路，尚不提供严格均衡求解、多轮 EV 或精确动作频率，也未接入联网大模型。所有筹码都是虚拟数值。

目录、游戏路由、纯规则与 React 界面各自维护。新增游戏的步骤和规则来源见 [游戏室与扩展](GAMES.md)；线上更新、独立构建与回滚见 [服务器部署](SELF-HOSTING.md)。
