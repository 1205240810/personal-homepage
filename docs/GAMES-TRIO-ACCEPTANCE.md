## 真实浏览器

使用独立 Microsoft Edge 测试会话访问主站的生产构建，未使用用户的账号或现有浏览器标签。查看桌面及移动宽度截图，同时以实际按钮操作验证流程。

- 游戏室：六个游戏入口、独立地址与返回机甲参数正确；桌面 1440px、手机 390px / 320px 无横向溢出。
- 数独：填写笔记、撤销、重做、擦除、应用推理、换题前取消、暂停及刷新恢复通过。通过教练完成一整道题，最后一步撤销再重做并刷新，完成记录保持 1 / 120，退出返回 `/games?from=explore`。
- 骰子：投掷、保留、暂停并刷新恢复通过；完成双方各 13 栏、26 条行动的整局对弈，结束页刷新后分数与记录保留。正分先预览再确认，零分可取消再确认。手机布局实测发现并修复横向溢出；最终 390px / 320px 的骰面、记分簿及展开设置均复测通过。
- 梭哈：开局焦点、C 过牌、有效全下确认的 Escape 取消、暂停及刷新后原状态恢复通过；一手逐轮到达摊牌并展开双方决策复盘，下一手确认有效全下后结算，筹码总数仍为 1000。退出返回原游戏室来路；1440px / 390px / 320px 无横向溢出。
- 加载恢复：人为阻断数独 JS 分块后出现加载失败提示；恢复网络并点击“重新加载”，重新获取页面后游戏正常挂载，已有存档保留。
- 正常流程中未发现浏览器控制台错误；上述故障注入产生一条预期的网络失败，单独记录。

截图保存在本机忽略目录 `output/games/trio-*.png`。便携版另外以禁用网络的执行环境验证正常挂载、无外部运行资源及执行错误。
