# 开源参考与许可

本项目参考以下开源项目的设计与组织方式，没有复制其场景图片、人物或第三方瓦片：

- [Phaser React TypeScript 官方模板](https://github.com/phaserjs/template-react-ts)，MIT：参考 React 生命周期与 Phaser 边界组织。
- [Bruno Simon Folio 2019](https://github.com/brunosimon/folio-2019)，MIT：参考可操控空间中的导航及环境反馈设计。
- [JSLegendDev 2D Portfolio](https://github.com/JSLegendDev/2d-portfolio-kaboom)，MIT：参考邻近物件提示、移动和阅读切换。

Phaser、React、TypeScript、KaTeX、Marked、sanitize-html、lucide-react 以及 Sites 模板依赖依各自分发包中的许可证使用。安装包保留 LICENSE；项目锁文件记录准确版本。Sites CLI 生成的 shadcn 组件保留在 components/ui 中。本项目原创场景资产不取自以上参考项目。

博客原文著作权归原作者，来源链接显示于各篇正文末尾。
